# Security Policy

resilint [v1.0.0](https://github.com/chriswayneh/resilint/releases/tag/v1.0.0) is published. See [Releases](https://github.com/chriswayneh/resilint/releases) for version history and the [v1 stability policy](docs/stability.md) for supported interfaces.

Report issues against the exact version and commit, including whether the build is a release candidate.

resilint runs offline and makes no network calls. Checks read your local YAML or CSV register without modifying it. Report and export commands write local output files, and `drill record` writes a local drill log.

To report a security issue, please use GitHub's private vulnerability reporting on this repository rather than a public issue. Do not include real vendor contracts or personal data in reports.
