Scope: CONTRIBUTING.md, bug/feature issue templates, the PR template, a README contributor link and changelog entry. Reconcile the prepared contributor wording with merged AGENTS and audit guidance. No runtime, tests, dependencies, CI, settings or installation changes.

Contributor guidance covers Python/venv setup, one task per PR, preserved history, lint/types/full tests/link/diff gates, hosted coverage and platform/Action checks, report snapshot review and private security reporting. Add explicit links to AGENTS and the workflow records, actual stage approval attribution and user-owned reserved actions subject only to documented explicit authorization. Templates retain fictional-only data, minimal reproduction, expected/actual behavior, relevant task IDs and verification evidence. GitHub-rendered template links use repository URLs.

Acceptance: D-6's required files exist; templates contain every gate command and the fictional-data rule; existing policy and scope are preserved; no invented approval or release claim; Markdown links and YAML frontmatter validate; no private data. Completion is effective only on merge.

Security: documentation must never solicit contracts, credentials, PHI/PII or real contacts. Preserve the private vulnerability route and comprehensive code/security-review requirements. No new execution, network behavior, SQL, dependencies or permissions; review these as inapplicable rather than inventing behavior tests.
